Everything you do with documents

Ask, edit, fill in, black out and compare. The AI does the work; you see a preview of the real file before anything is downloaded.

Ask
Answers cite the exact passage. Long documents are searched by meaning, so the question doesn't have to use the document's words.
Edit
Changes go into your original PDF, Word, Excel or PowerPoint file. Logos, fonts and layout stay exactly as they were.
Compare
Two versions of a contract? See every changed word, and get an explanation of what it means for you.
Black out
Names, addresses, IBANs and ID numbers are found and truly removed from the file, not just covered.
Fill in
PDF forms are filled from what you tell it and your other documents. You check every field.
Scans
Scanned letters and phone photos are read with text recognition in German and English.

What happens to your file

Most document AI tools put your files in a database and keep them. Paradox has no database. A file exists for exactly as long as you are using it.

  1. You upload it

    The file is read straight from the request into memory. It is never saved as a temp file.

  2. It is indexed in RAM

    Text is split into passages and turned into search vectors, held in your session only.

  3. You ask questions

    Paradox finds the relevant passages and answers with clickable citations.

  4. It is gone

    Sign out, go idle, or stop the server and the session is destroyed.

    idle 30 min → wiped

Built like a security tool

Written by someone from IT security, for people who have to answer to auditors. Check every claim yourself →

Storage
No database. Nothing written to disk, enforced by a test that fails if it is.
Isolation
Every user's workspaces are scoped to their own session.
Logins
bcrypt password hashes, rate limiting, fresh session token on every login.
Browser
HttpOnly SameSite cookies, CSRF tokens, strict CSP, no caching.
Prompt injection
Document text is fenced as data and cannot forge the model's instructions.
Container
Read-only filesystem, RAM-only scratch space, all capabilities dropped.
