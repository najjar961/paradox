Security

Don't trust us. Check it.

Paradox makes one promise: your documents are not uploaded and not stored. Here is exactly what that means, and how you can verify it yourself in about five minutes, without reading any code.

One-page summary for your IT department (PDF)

The promise, precisely

Paradox Lite in your browser

  • Your files are read inside the page. They never leave your device.
  • The AI runs on your own graphics card. There is no Paradox server that could receive anything.
  • Files and chats exist only in the page's memory. Closing the tab deletes them.
  • The only things downloaded are this app and public AI models from Hugging Face. Nothing is uploaded.

Self-hosted your server

  • Files, search data and chats live only in the server's RAM, for one login session.
  • Sign-out, 30 minutes idle, the session time limit or a restart deletes them.
  • No database, no files written, no document text in logs. A test fails if anything is written to disk.
  • With Ollama, nothing leaves your server at all.

Check Paradox Lite yourself

You need Chrome or Edge on a computer. Each check takes about a minute.

  1. Watch every connection

    Open Paradox Lite and press F12 (Mac: ⌥⌘I). Click the Network tab, then upload a document and ask a question.

    You will see requests only to najjar961.github.io (the app itself) and, while a model downloads, to huggingface.co or raw.githubusercontent.com. All of them are downloads (GET). Your document never appears in any request, because none is ever made with it.

  2. Pull the plug

    Load a model once, so it is saved in your browser. Then turn off Wi-Fi, or tick Offline in the Network tab, and reload the page.

    Paradox still opens, reads your files and answers. A tool that works with no internet at all cannot be sending your documents anywhere.

  3. Look at what the browser stored

    In the developer tools, open Application → Storage. Local storage, Session storage and IndexedDB are empty for Paradox.

    Cache storage holds only program files: paradox-shell and paradox-vendor (the app, for offline use), webllm/… (the AI model) and transformers-cache (the search model). Open them: there is no document and no chat inside.

  4. Read the lock the browser enforces

    Right-click the page → View page source. Near the top is a Content-Security-Policy. Its connect-src line lists the only sites the page may contact: itself and the model hosts. The browser blocks everything else, even if the code had a bug.

  5. Check the code and the tests

    Every line is public on GitHub. Third-party libraries are unmodified copies, listed with versions in LICENSES.md. Every change runs the automatic tests, including tests in a real browser, which you can see under Actions.

Check the self-hosted version

  1. Nothing on disk

    The container's file system is read-only, so the app could not save a file even if it tried:

    docker compose exec paradox touch /srv/test
→ touch: cannot touch '/srv/test': Read-only file system

    The only writable folder, /tmp, is a RAM disk. Upload a document and look inside: your document isn't there.

    docker compose exec paradox ls -la /tmp

    The test test_nothing_written_to_disk also fails if the app opens any file for writing during upload or chat.

  2. Nothing in the logs

    docker compose logs paradox

    You see start-up lines, not file names, questions or answers. The access log is switched off.

  3. Gone after sign-out

    Sign out and sign in again: the workspace is empty. The server holds no copy it could restore.

  4. Nothing leaves your network

    With LLM_PROVIDER=ollama and EMBED_PROVIDER=ollama the AI runs in the ollama container next to Paradox. You can cut the server's internet access after the models are downloaded and everything keeps working.

Honest limits

  • Your device matters. Paradox can't protect a document from malware or browser extensions that can read every page you open. Use a clean browser profile for sensitive files.
  • Downloads are visible. GitHub (which hosts this site) and Hugging Face see your IP address when you load the app or a model, like any website. They never see your documents or questions.
  • The browser caches the AI model, so the next start is fast. That cache contains only the public model. Remove it with “Remove downloaded model from this browser”.
  • Memory isn't shredded. Deleted data stays in RAM until it is overwritten. On a server, turn off swap or encrypt it.
  • Hosted models are a choice with a cost. If the self-hosted app is set to OpenAI or Anthropic, the relevant passages and your questions go to that provider.
  • AI makes mistakes. Answers cite their sources, edits and redactions show a preview of the real file, and comparisons are computed exactly, so you can check. Automatic detection of personal data can miss things.

Sicherheit

Vertrauen Sie uns nicht. Prüfen Sie es.

Paradox gibt ein Versprechen: Ihre Dokumente werden nicht hochgeladen und nicht gespeichert. Hier steht genau, was das heißt, und wie Sie es in etwa fünf Minuten selbst nachprüfen, ohne Code zu lesen.

Einseitige Übersicht für Ihre IT-Abteilung (PDF)

Das Versprechen, genau

Paradox Lite im Browser

  • Ihre Dateien werden in der Seite gelesen. Sie verlassen Ihr Gerät nie.
  • Die KI läuft auf Ihrer eigenen Grafikkarte. Es gibt keinen Paradox-Server, der etwas empfangen könnte.
  • Dateien und Chats existieren nur im Arbeitsspeicher der Seite. Schließen Sie den Tab, sind sie gelöscht.
  • Heruntergeladen werden nur diese App und öffentliche KI-Modelle von Hugging Face. Hochgeladen wird nichts.

Selbst gehostet Ihr Server

  • Dateien, Suchdaten und Chats liegen nur im Arbeitsspeicher des Servers, für eine Anmeldesitzung.
  • Abmelden, 30 Minuten Inaktivität, das Sitzungslimit oder ein Neustart löscht sie.
  • Keine Datenbank, keine geschriebenen Dateien, kein Dokumenttext in Logs. Ein Test schlägt fehl, sobald etwas auf die Festplatte geschrieben wird.
  • Mit Ollama verlässt gar nichts Ihren Server.

Paradox Lite selbst prüfen

Sie brauchen Chrome oder Edge auf einem Computer. Jede Prüfung dauert etwa eine Minute.

  1. Jede Verbindung beobachten

    Öffnen Sie Paradox Lite und drücken Sie F12 (Mac: ⌥⌘I). Klicken Sie auf den Reiter Netzwerk, laden Sie dann ein Dokument hoch und stellen Sie eine Frage.

    Sie sehen nur Anfragen an najjar961.github.io (die App selbst) und, während ein Modell lädt, an huggingface.co oder raw.githubusercontent.com. Alles sind Downloads (GET). Ihr Dokument taucht in keiner Anfrage auf, weil nie eine damit gestellt wird.

  2. Den Stecker ziehen

    Laden Sie einmal ein Modell, damit es im Browser gespeichert ist. Schalten Sie dann das WLAN aus, oder setzen Sie im Netzwerk-Reiter den Haken bei Offline, und laden Sie die Seite neu.

    Paradox öffnet sich trotzdem, liest Ihre Dateien und antwortet. Ein Werkzeug, das ganz ohne Internet funktioniert, kann Ihre Dokumente nirgendwohin schicken.

  3. Ansehen, was der Browser gespeichert hat

    Öffnen Sie in den Entwicklertools Anwendung → Speicher. Lokaler Speicher, Sitzungsspeicher und IndexedDB sind für Paradox leer.

    Der Cache-Speicher enthält nur Programmdateien: paradox-shell und paradox-vendor (die App, für die Offline-Nutzung), webllm/… (das KI-Modell) und transformers-cache (das Suchmodell). Öffnen Sie sie: Darin ist kein Dokument und kein Chat.

  4. Das Schloss lesen, das der Browser durchsetzt

    Rechtsklick auf die Seite → Seitenquelltext anzeigen. Oben steht eine Content-Security-Policy. Ihre Zeile connect-src nennt die einzigen Adressen, mit denen die Seite sprechen darf: sich selbst und die Modell-Server. Alles andere blockiert der Browser, selbst wenn der Code einen Fehler hätte.

  5. Code und Tests ansehen

    Jede Zeile ist öffentlich auf GitHub. Fremde Bibliotheken sind unveränderte Kopien, mit Versionen aufgelistet in LICENSES.md. Jede Änderung durchläuft die automatischen Tests, auch Tests in einem echten Browser. Sie sehen sie unter Actions.

Die selbst gehostete Version prüfen

  1. Nichts auf der Festplatte

    Das Dateisystem des Containers ist schreibgeschützt. Die App könnte also keine Datei speichern, selbst wenn sie es versuchte:

    docker compose exec paradox touch /srv/test
→ touch: cannot touch '/srv/test': Read-only file system

    Der einzige beschreibbare Ordner, /tmp, ist ein RAM-Laufwerk. Laden Sie ein Dokument hoch und sehen Sie nach: Ihr Dokument ist nicht dort.

    docker compose exec paradox ls -la /tmp

    Außerdem schlägt der Test test_nothing_written_to_disk fehl, sobald die App beim Hochladen oder Chatten irgendeine Datei zum Schreiben öffnet.

  2. Nichts in den Logs

    docker compose logs paradox

    Sie sehen Startmeldungen, keine Dateinamen, Fragen oder Antworten. Das Zugriffsprotokoll ist abgeschaltet.

  3. Weg nach dem Abmelden

    Melden Sie sich ab und wieder an: Der Arbeitsbereich ist leer. Der Server hat keine Kopie, die er wiederherstellen könnte.

  4. Nichts verlässt Ihr Netzwerk

    Mit LLM_PROVIDER=ollama und EMBED_PROVIDER=ollama läuft die KI im Container ollama neben Paradox. Nach dem Herunterladen der Modelle können Sie dem Server den Internetzugang kappen, und alles funktioniert weiter.

Ehrliche Grenzen

  • Ihr Gerät zählt. Paradox kann ein Dokument nicht vor Schadsoftware oder Browser-Erweiterungen schützen, die jede Seite mitlesen. Nutzen Sie für vertrauliche Dateien ein sauberes Browserprofil.
  • Downloads sind sichtbar. GitHub (Hoster dieser Seite) und Hugging Face sehen Ihre IP-Adresse, wenn Sie die App oder ein Modell laden, wie bei jeder Website. Ihre Dokumente und Fragen sehen sie nie.
  • Der Browser speichert das KI-Modell zwischen, damit der nächste Start schnell geht. Dieser Cache enthält nur das öffentliche Modell. Löschen Sie ihn mit „Heruntergeladenes Modell aus diesem Browser löschen“.
  • Arbeitsspeicher wird nicht geschreddert. Gelöschte Daten bleiben im RAM, bis sie überschrieben werden. Schalten Sie auf einem Server Swap ab oder verschlüsseln Sie ihn.
  • Gehostete Modelle haben ihren Preis. Ist die selbst gehostete App auf OpenAI oder Anthropic eingestellt, gehen die relevanten Textstellen und Ihre Fragen an diesen Anbieter.
  • KI macht Fehler. Antworten nennen ihre Quellen, Änderungen und Schwärzungen zeigen eine Vorschau der echten Datei, und Vergleiche werden exakt berechnet, damit Sie nachprüfen können. Die automatische Erkennung persönlicher Daten kann etwas übersehen.

Sécurité

Ne nous faites pas confiance. Vérifiez.

Paradox fait une seule promesse : vos documents ne sont ni envoyés ni enregistrés. Voici exactement ce que cela veut dire, et comment le vérifier vous-même en cinq minutes environ, sans lire une ligne de code.

Résumé d'une page pour votre service informatique (PDF, en anglais)

La promesse, précisément

Paradox Lite dans votre navigateur

  • Vos fichiers sont lus dans la page. Ils ne quittent jamais votre appareil.
  • L'IA tourne sur votre propre carte graphique. Il n'existe aucun serveur Paradox qui pourrait recevoir quoi que ce soit.
  • Les fichiers et les conversations n'existent que dans la mémoire de la page. Fermer l'onglet les efface.
  • Seuls l'application et des modèles d'IA publics de Hugging Face sont téléchargés. Rien n'est envoyé.

Auto-hébergé votre serveur

  • Les fichiers, les données de recherche et les conversations restent uniquement dans la RAM du serveur, le temps d'une session.
  • La déconnexion, 30 minutes d'inactivité, la durée maximale de session ou un redémarrage les efface.
  • Pas de base de données, aucun fichier écrit, aucun texte de document dans les journaux. Un test échoue si quoi que ce soit est écrit sur le disque.
  • Avec Ollama, rien ne quitte votre serveur.

Vérifiez Paradox Lite vous-même

Il vous faut Chrome ou Edge sur un ordinateur. Chaque vérification prend environ une minute.

  1. Observez chaque connexion

    Ouvrez Paradox Lite et appuyez sur F12 (Mac : ⌥⌘I). Cliquez sur l'onglet Réseau, puis chargez un document et posez une question.

    Vous ne verrez des requêtes que vers najjar961.github.io (l'application elle-même) et, pendant le téléchargement d'un modèle, vers huggingface.co ou raw.githubusercontent.com. Ce sont toutes des téléchargements (GET). Votre document n'apparaît dans aucune requête, parce qu'aucune n'est jamais faite avec lui.

  2. Coupez Internet

    Chargez un modèle une fois, pour qu'il soit enregistré dans votre navigateur. Coupez ensuite le Wi-Fi, ou cochez Hors connexion dans l'onglet Réseau, et rechargez la page.

    Paradox s'ouvre toujours, lit vos fichiers et répond. Un outil qui fonctionne sans aucune connexion ne peut envoyer vos documents nulle part.

  3. Regardez ce que le navigateur a enregistré

    Dans les outils de développement, ouvrez Application → Stockage. Local storage, Session storage et IndexedDB sont vides pour Paradox.

    Cache storage ne contient que des fichiers de programme : paradox-shell et paradox-vendor (l'application, pour l'usage hors connexion), webllm/… (le modèle d'IA) et transformers-cache (le modèle de recherche). Ouvrez-les : il n'y a ni document ni conversation.

  4. Lisez le verrou imposé par le navigateur

    Clic droit sur la page → Afficher le code source. En haut se trouve une Content-Security-Policy. Sa ligne connect-src liste les seuls sites que la page peut contacter : elle-même et les hébergeurs des modèles. Le navigateur bloque tout le reste, même si le code contenait une erreur.

  5. Vérifiez le code et les tests

    Chaque ligne est publique sur GitHub. Les bibliothèques tierces sont des copies non modifiées, listées avec leurs versions dans LICENSES.md. Chaque modification lance les tests automatiques, y compris dans un vrai navigateur, visibles sous Actions.

Vérifiez la version auto-hébergée

  1. Rien sur le disque

    Le système de fichiers du conteneur est en lecture seule : l'application ne pourrait pas enregistrer de fichier même si elle essayait.

    docker compose exec paradox touch /srv/test
→ touch: cannot touch '/srv/test': Read-only file system

    Le seul dossier inscriptible, /tmp, est un disque en RAM. Chargez un document et regardez dedans : votre document n'y est pas.

    docker compose exec paradox ls -la /tmp

    Le test test_nothing_written_to_disk échoue aussi si l'application ouvre un fichier en écriture pendant un envoi ou une conversation.

  2. Rien dans les journaux

    docker compose logs paradox

    Vous voyez des lignes de démarrage, pas de noms de fichiers, de questions ni de réponses. Le journal d'accès est désactivé.

  3. Effacé après la déconnexion

    Déconnectez-vous et reconnectez-vous : l'espace de travail est vide. Le serveur ne garde aucune copie qu'il pourrait restaurer.

  4. Rien ne quitte votre réseau

    Avec LLM_PROVIDER=ollama et EMBED_PROVIDER=ollama, l'IA tourne dans le conteneur ollama à côté de Paradox. Vous pouvez couper l'accès Internet du serveur une fois les modèles téléchargés, et tout continue de fonctionner.

Limites, en toute honnêteté

  • Votre appareil compte. Paradox ne peut pas protéger un document contre un logiciel malveillant ou une extension de navigateur capable de lire chaque page. Utilisez un profil de navigateur propre pour les fichiers sensibles.
  • Les téléchargements sont visibles. GitHub (qui héberge ce site) et Hugging Face voient votre adresse IP quand vous chargez l'application ou un modèle, comme pour tout site web. Ils ne voient jamais vos documents ni vos questions.
  • Le navigateur met le modèle d'IA en cache, pour que le prochain démarrage soit rapide. Ce cache ne contient que le modèle public. Supprimez-le avec « Supprimer le modèle téléchargé de ce navigateur ».
  • La mémoire n'est pas broyée. Les données effacées restent dans la RAM jusqu'à ce qu'elles soient écrasées. Sur un serveur, désactivez le swap ou chiffrez-le.
  • Les modèles hébergés ont un prix. Si l'application auto-hébergée utilise OpenAI ou Anthropic, les passages concernés et vos questions sont envoyés à ce fournisseur.
  • L'IA fait des erreurs. Les réponses citent leurs sources, les modifications et caviardages montrent un aperçu du vrai fichier, et les comparaisons sont calculées exactement, pour que vous puissiez vérifier. La détection automatique des données personnelles peut en manquer.

الأمان

لا تثق بنا. تحقّق بنفسك.

يقدّم Paradox وعدًا واحدًا: مستنداتك لا تُرفع ولا تُحفظ. إليك ما يعنيه ذلك بالضبط، وكيف تتحقق منه بنفسك في نحو خمس دقائق، دون قراءة أي سطر من الشيفرة.

ملخّص من صفحة واحدة لقسم تقنية المعلومات (PDF، بالإنجليزية)

الوعد، بدقّة

Paradox Lite في متصفحك

  • تُقرأ ملفاتك داخل الصفحة، ولا تغادر جهازك أبدًا.
  • يعمل الذكاء الاصطناعي على بطاقة الرسوميات في جهازك. لا يوجد خادم لـ Paradox يمكن أن يستقبل أي شيء.
  • الملفات والمحادثات موجودة في ذاكرة الصفحة فقط. إغلاق التبويب يحذفها.
  • لا يُنزَّل سوى هذا التطبيق ونماذج ذكاء اصطناعي عامة من Hugging Face. لا يُرفع شيء.

استضافة ذاتية خادمك

  • تبقى الملفات وبيانات البحث والمحادثات في ذاكرة الخادم (RAM) فقط، طوال جلسة دخول واحدة.
  • تُحذف عند تسجيل الخروج، أو بعد 30 دقيقة من عدم النشاط، أو عند انتهاء مدة الجلسة، أو عند إعادة التشغيل.
  • لا قاعدة بيانات، ولا ملفات تُكتب، ولا نصوص مستندات في السجلات. يفشل اختبار إذا كُتب أي شيء على القرص.
  • مع Ollama، لا يغادر شيء خادمك على الإطلاق.

تحقّق من Paradox Lite بنفسك

تحتاج إلى Chrome أو Edge على حاسوب. كل خطوة تستغرق نحو دقيقة.

  1. راقب كل اتصال

    افتح Paradox Lite واضغط F12 (على Mac: ⌥⌘I). اختر تبويب Network، ثم ارفع مستندًا واطرح سؤالًا.

    سترى طلبات إلى najjar961.github.io فقط (التطبيق نفسه)، وأثناء تنزيل نموذج إلى huggingface.co أو raw.githubusercontent.com. كلها تنزيلات (GET). لا يظهر مستندك في أي طلب، لأنه لا يُرسل أي طلب به أصلًا.

  2. اقطع الإنترنت

    حمّل نموذجًا مرة واحدة ليُحفظ في متصفحك. ثم أطفئ Wi-Fi، أو فعّل Offline في تبويب Network، وأعد تحميل الصفحة.

    يظل Paradox يفتح ويقرأ ملفاتك ويجيب. أداة تعمل دون أي اتصال بالإنترنت لا يمكنها إرسال مستنداتك إلى أي مكان.

  3. انظر إلى ما حفظه المتصفح

    في أدوات المطوّر، افتح Application ← Storage. ستجد Local storage وSession storage وIndexedDB فارغة بالنسبة لـ Paradox.

    لا يحتوي Cache storage إلا على ملفات البرنامج: paradox-shell وparadox-vendor (التطبيق، للعمل دون اتصال)، وwebllm/… (نموذج الذكاء الاصطناعي)، وtransformers-cache (نموذج البحث). افتحها: لا يوجد فيها أي مستند أو محادثة.

  4. اقرأ القفل الذي يفرضه المتصفح

    انقر بزر الفأرة الأيمن على الصفحة ← View page source. ستجد في الأعلى Content-Security-Policy. يذكر سطر connect-src المواقع الوحيدة التي يمكن للصفحة الاتصال بها: نفسها ومستضيفي النماذج. يحظر المتصفح كل ما عدا ذلك، حتى لو كان في الشيفرة خطأ.

  5. تحقّق من الشيفرة والاختبارات

    كل سطر منشور علنًا على GitHub. المكتبات الخارجية نسخ غير معدّلة، مدرجة مع إصداراتها في LICENSES.md. كل تعديل يشغّل الاختبارات الآلية، بما فيها اختبارات في متصفح حقيقي، ويمكنك رؤيتها في Actions.

تحقّق من نسخة الاستضافة الذاتية

  1. لا شيء على القرص

    نظام ملفات الحاوية للقراءة فقط، فلا يستطيع التطبيق حفظ أي ملف حتى لو حاول:

    docker compose exec paradox touch /srv/test
→ touch: cannot touch '/srv/test': Read-only file system

    المجلد الوحيد القابل للكتابة، /tmp، قرص في الذاكرة. ارفع مستندًا وانظر داخله: مستندك ليس هناك.

    docker compose exec paradox ls -la /tmp

    ويفشل الاختبار test_nothing_written_to_disk أيضًا إذا فتح التطبيق أي ملف للكتابة أثناء الرفع أو المحادثة.

  2. لا شيء في السجلات

    docker compose logs paradox

    سترى أسطر بدء التشغيل فقط، لا أسماء ملفات ولا أسئلة ولا أجوبة. سجل الوصول معطّل.

  3. يختفي بعد تسجيل الخروج

    سجّل الخروج ثم ادخل مجددًا: مساحة العمل فارغة. لا يحتفظ الخادم بأي نسخة يمكنه استعادتها.

  4. لا شيء يغادر شبكتك

    مع LLM_PROVIDER=ollama وEMBED_PROVIDER=ollama يعمل الذكاء الاصطناعي في حاوية ollama بجانب Paradox. يمكنك قطع الإنترنت عن الخادم بعد تنزيل النماذج، وسيستمر كل شيء في العمل.

حدود، بصراحة

  • جهازك مهم. لا يستطيع Paradox حماية مستند من برمجيات خبيثة أو إضافات متصفح تقرأ كل صفحة تفتحها. استخدم ملف تعريف نظيفًا في المتصفح للملفات الحساسة.
  • التنزيلات مرئية. يرى GitHub (الذي يستضيف هذا الموقع) وHugging Face عنوان IP الخاص بك عند تحميل التطبيق أو نموذج، كأي موقع ويب. لكنهما لا يريان مستنداتك أو أسئلتك أبدًا.
  • يخزّن المتصفح نموذج الذكاء الاصطناعي مؤقتًا ليكون التشغيل التالي سريعًا. لا يحتوي هذا التخزين إلا على النموذج العام. احذفه عبر «حذف النموذج المنزّل من هذا المتصفح».
  • الذاكرة لا تُمحى فورًا. تبقى البيانات المحذوفة في الذاكرة حتى يُكتب فوقها. على الخادم، أوقف ذاكرة التبديل (swap) أو شفّرها.
  • للنماذج المستضافة ثمن. إذا ضُبط التطبيق المستضاف ذاتيًا على OpenAI أو Anthropic، تُرسل المقاطع ذات الصلة وأسئلتك إلى ذلك المزوّد.
  • الذكاء الاصطناعي يخطئ. تذكر الأجوبة مصادرها، وتعرض التعديلات والتنقيحات معاينة للملف الحقيقي، وتُحسب المقارنات بدقة، لتتمكن من التحقق. وقد يفوت الكشفَ الآلي عن البيانات الشخصية بعضُها.
